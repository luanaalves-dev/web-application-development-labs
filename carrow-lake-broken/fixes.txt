2. index.html: The main picture did not show because src pointed to "images/ridge.jpeg" instead of "images/ridge.jpg". Fixed the file extension to ".jpg".
3. index.html: The email address in the footer did not appear on the page because "<boats@example.com>" was written with raw angle brackets and treated as an HTML tag. Fixed by replacing them with "&lt;boats@example.com&gt;".
4. hire.html: The Home link gave a file not found error because href was written as "index.htm" (missing the "l"). Fixed by changing href to "index.html".
5. hire.html: The lake picture did not show because src used a local Windows path ("C:\Users\Student\Pictures\lake.jpg"). Fixed by changing src to the relative path "images/lake.jpg".
6. pages/prices.html: The compass picture did not show because src pointed to "images/compass.jpg" instead of going up one folder level. Fixed by changing src to "../images/compass.jpg".
7. pages/prices.html: The logo used a capital "L" ("../images/Logo.svg"), which works on Windows but breaks on case-sensitive web servers since the file is "logo.svg". Fixed by changing it to "../images/logo.svg".

Validator notes:
